# Nano Banana Illustration Style Guide

## Visual Identity Overview

This style guide documents the illustration style for consistent branding across all generated images.

---

## Style Characteristics

### Art Style
- **Type**: Flat vector illustration / Digital art
- **Rendering**: Clean, crisp edges with no gradients
- **Outlines**: Bold dark outlines (appears to be dark brown/black)
- **Complexity**: Medium detail - stylized but recognizable
- **Aesthetic**: Modern, professional, approachable

### Color Palette

| Color | Hex (approx) | Usage |
|-------|--------------|-------|
| Coral Pink | `#E8A0A0` | Background circle, accent shapes |
| Teal/Cyan | `#5B9A9A` | Accent shapes, geometric elements |
| Cream/Off-white | `#F5F0EB` | Main background |
| Tan/Camel | `#C4A574` | Leopard print base |
| Dark Brown | `#3D2B1F` | Outlines, leopard spots, hair |
| Warm Beige | `#E5CEB5` | Skin tones |

### Composition Elements
- **Circular framing**: Pink/coral oval backdrop behind subject
- **Geometric shapes**: Hexagons and rectangles as decorative elements
- **Balanced layout**: Centered subject with asymmetric details

### Character Style
- **Proportions**: Realistic but slightly stylized
- **Hair**: Detailed curls with individual strand definition
- **Expression**: Confident, approachable smile
- **Clothing**: Bold patterns (leopard print), fashion-forward

## Prompt Templates

### Base Prompt Structure
```
[Subject description], flat vector illustration style, bold dark outlines,
limited color palette (coral pink, teal, cream, tan), clean crisp edges,
no gradients, modern professional aesthetic, circular pink backdrop,
geometric accent shapes
```

### Variations

#### Portrait Illustration
```
Portrait of [subject], flat vector illustration, bold outlines,
coral and teal accent colors, cream background with pink circular frame,
stylized but recognizable features, confident expression,
modern digital art style, clean edges
```

#### Scene Illustration
```
[Scene description], flat vector art style, limited palette
(coral #E8A0A0, teal #5B9A9A, cream #F5F0EB, tan #C4A574),
bold dark outlines, geometric decorative elements,
professional branding illustration
```

#### Icon/Element
```
[Element description], flat vector style, matching nano banana brand colors,
bold outlines, geometric shapes, teal and coral accents,
clean minimal design
```

## Style Keywords Reference

### Must Include
- flat vector illustration
- bold dark outlines
- limited color palette
- clean crisp edges
- no gradients
- modern aesthetic

### Optional Modifiers
- geometric accent shapes
- circular framing
- professional branding style
- stylized portrait
- fashion illustration influence

### Avoid
- photorealistic
- 3D rendering
- heavy shadows
- complex gradients
- muted/desaturated colors
- rough/sketchy lines

---

## Use Cases

### 1. Social Media Avatars
- Circular crop friendly (use pink backdrop)
- High contrast for small sizes
- Recognizable silhouette

### 2. Marketing Materials
- Scalable vector style works at any size
- Consistent brand colors across materials
- Professional yet approachable

### 3. Website/App Graphics
- Clean style matches modern UI
- Geometric elements for icons/buttons
- Illustration can anchor hero sections

### 4. Print Collateral
- Bold outlines reproduce well in print
- Limited palette keeps printing costs down
- Distinctive style stands out

---

## Image Analysis Checklist

When reviewing generated images for brand consistency, check:

- [ ] Uses flat colors (no gradients)
- [ ] Has bold, consistent outline weight
- [ ] Colors match palette (coral, teal, cream, tan, brown)
- [ ] Clean, crisp edges
- [ ] Modern, professional feel
- [ ] Geometric elements present (if applicable)
- [ ] Circular/oval framing (if portrait)
